GraphQL vs REST API

GraphQL cho phép bạn lấy chính xác dữ liệu cần thiết với một request duy nhất. Không cần nhiều API calls như REST!

REST API (Cách cũ)

Nhiều API calls:

  1. GET /api/products (lấy danh sách)
  2. GET /api/categories/1 (lấy thông tin danh mục)
  3. GET /api/users/100001 (lấy thông tin user)

3 requests = 3 lần gọi server

GraphQL (Cách mới)

Một API call duy nhất:

query { products { id productName price category { categoryName } user { fullName } } }

1 request = 1 lần gọi server
