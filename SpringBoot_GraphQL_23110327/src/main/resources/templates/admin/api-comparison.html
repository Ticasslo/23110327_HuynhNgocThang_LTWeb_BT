REST API (Cách cũ)
Để lấy thông tin sản phẩm với danh mục và người tạo:
Request 1:
GET /api/products
Response:
[ { "id": 1, "productName": "iPhone 15", "price": 25000000, "categoryId": 1, "userId": 100001 } ]
Request 2:
GET /api/categories/1
Response:
{ "id": 1, "categoryName": "Điện tử" }
Request 3:
GET /api/users/100001
Response:
{ "id": 100001, "fullName": "Huynh Ngoc Thang" }
Vấn đề:
  • 3 requests riêng biệt
  • Over-fetching (lấy dữ liệu thừa)
  • Under-fetching (thiếu dữ liệu)
  • Chậm và tốn băng thông
GraphQL (Cách mới)
Để lấy thông tin sản phẩm với danh mục và người tạo:
Request (1 request duy nhất):
POST /graphql
{ "query": "query { products { id productName price category { categoryName } user { fullName } } }" }
Response:
{ "data": { "products": [ { "id": "1", "productName": "iPhone 15", "price": 25000000, "category": { "categoryName": "Điện tử" }, "user": { "fullName": "Huynh Ngoc Thang" } } ] } }
Ưu điểm:
  • 1 request duy nhất
  • Chỉ lấy dữ liệu cần thiết
  • Không over-fetching
  • Nhanh và tiết kiệm băng thông
Khi nào dùng REST vs GraphQL?
Dùng REST khi:
  • API đơn giản, ít phức tạp
  • Cần cache HTTP responses
  • Team chưa quen GraphQL
  • Microservices architecture
  • Cần HTTP status codes
Dùng GraphQL khi:
  • Frontend cần dữ liệu phức tạp
  • Mobile app cần tiết kiệm băng thông
  • API có nhiều relationships
  • Cần type safety
  • Real-time subscriptions
